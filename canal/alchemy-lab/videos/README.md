# Vídeos de Alchemy Lab

Crie `videos/<id>/video.json`. Sem `modelo`, o vídeo herda o modelo padrão em `../canal.json`. Defina `"modelo": "camadas-animadas"` ou `"modelo": "imagem-estatica"` para trocar apenas neste vídeo.

Não importar automaticamente manifestos de upload antigos: eles usam outro esquema. Manter arquivos gerados em `output/` fora do Git.
